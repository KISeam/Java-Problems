1. 🧠 Java Quiz Game

A simple and interactive **Java Console Quiz Game** that tests your general knowledge with multiple-choice questions.  
This project is perfect for beginners learning **Java basics**, such as arrays, loops, conditional statements, and user input handling using `Scanner`.

---

## 🚀 Features

- 🎯 5 multiple-choice questions  
- 🧩 Dynamic question and option arrays  
- 🏆 Automatic scoring system  
- 💬 Real-time feedback after each question  
- 👨‍💻 Beginner-friendly and easy to extend
